# LX Music List Transform

使用方法：

1. 在搜索框中输入 `>`，进入命令模式。
2. 找到并选择 **「转换 LX Music 列表数据」** 命令。
3. 在文件选择器中选择从 LX Music 导出的列表备份文件。
4. 选择转换后列表数据的保存位置。
5. 打开 _设置 > 备份与恢复_，点击 **「恢复数据」**，然后选择刚才保存的文件。

---

How to use:

1. Enter `>` in the search box to switch to command mode.
2. Find and select the **Convert LX Music List Data** command.
3. In the file picker, select the list backup file exported from LX Music.
4. Choose where to save the converted list data.
5. Open **Settings - Backup and Restore**, click **Restore Data**, and select the file you just saved.
